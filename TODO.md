# Mobile Responsiveness Plan for Oldman's Tavern

## Overview
Make the entire site mobile-friendly by adding responsive design (media queries, flexible layouts, touch-friendly elements). Ensure all pages (index, menu, order forms, etc.) adapt to mobile screens (e.g., stack elements, adjust font sizes, make buttons larger).

## Steps
1. **Update style.css** - Add media queries for mobile and tablet, adjust title, buttons, sidebar, newsletter, popups.
2. **Update test menu.css** - Make menu items stack on mobile, adjust cart popup, title, buttons.
3. **Update buyphase.css** - Stack form elements, reduce sizes, make touch-friendly.
4. **Update delivery.css** - Similar to buyphase, stack form, adjust container.
5. **Update CantDecideYet.css** - Adjust popup, buttons, container for mobile.
6. **Update Blog.css** - Adjust title, container padding, text sizes.
7. **Test Responsiveness** - Use browser dev tools to simulate mobile, check all pages.
8. **Confirm with User** - Ensure changes work as expected.
